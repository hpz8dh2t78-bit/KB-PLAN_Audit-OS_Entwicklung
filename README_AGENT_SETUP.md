# KB-PLAN V18.0 Core — Agent Package v2

## Zweck
Dieses Paket ist die aktualisierte Arbeitsbasis für den Agentenbau auf Basis von **KB-PLAN_V18.0_Core_AGENT_PACKAGE.zip**, erweitert um das **Tutorial-/Onboarding-Modul**.

## Enthalten
1. `Instructions.md` — direkt in Agent Builder einfügen
2. `Runtime_v1.1.md` — kompakte Runtime-Fassung mit Onboarding-Hinweis
3. `Blocking_Matrix.md` — Stop-/HOLD-Regeln
4. `Testfaelle.md` — schnelle Härtetests
5. `Onboarding_Modul.md` — geführter Einstieg für neue Anwender
6. `Einfuehrung_Gefuehrte_Demo.md` — Lern-/Demo-Leitfaden
7. `Release_Notes_v2.md` — Änderungen gegenüber der bisherigen Arbeitsbasis
8. `Paketinhalt_v2.md` — Inhaltsübersicht

## Schnellstart
1. Microsoft 365 Copilot → Agent Builder öffnen
2. Neuen Agent anlegen
3. Inhalt aus `Instructions.md` in das Instructions-Feld kopieren
4. Optional: `Onboarding_Modul.md` als Referenz für Start-/Tutoriallogik verwenden
5. Agent speichern und mit `Testfaelle.md` prüfen
