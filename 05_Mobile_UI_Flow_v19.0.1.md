# 05 – Mobile UI Flow V19.0.1

## Ziel
Der Mobile-Flow soll Datenerfassung, Bildaufnahme und Abschlusslogik mit minimaler Reibung unterstützen.

## Mobile Kernschritte
1. Projekt auswählen oder neu anlegen
2. Pflichtdaten erfassen
3. Bilder aufnehmen / zuordnen
4. Prüfpunkte ergänzen
5. Daten synchronisieren
6. Gate-Status prüfen
7. Ergebnislauf auslösen

## UX-Regeln
- nur notwendige Fragen stellen
- Status deutlich anzeigen
- fehlende Muss-Daten sichtbar markieren
- Bilder fest zuordnen statt lose sammeln

## Mobile Statusanzeige
- Daten offen
- Template offen
- Bilder offen
- bereit zur Erstellung
- HOLD
- STOP
- abgeschlossen
