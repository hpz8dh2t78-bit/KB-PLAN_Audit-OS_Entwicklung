# 11 – Setup Copilot Agent V19.0.1

## Ziel
Diese Datei beschreibt das empfohlene Setup für die operative Verwendung des KB-PLAN-V19.0.1-Agenten.

## Setup-Bausteine
1. V19.0.1 als aktive Basis setzen
2. V18.0 nur als Referenz behandeln
3. Basisordner definieren
4. Template-Ablage für freigegebene `.dotx`-Vorlagen festlegen
5. Fallback-Skelett verfügbar halten
6. Testprojekt für Erstvalidierung anlegen

## Mindestkonfiguration
- definierter Projektordner
- definierter Vorlagenordner
- definierter Output-Ordner
- klare Statuslogik
- aktivierte Template-Gate-Prüfung

## Betriebsregel
Vor produktiver Nutzung mindestens einen Testfall mit vollständigem Abschluss durchlaufen.
